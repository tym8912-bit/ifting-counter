# リフティングカウンター(試作版)

## バージョン

| バージョン | 内容 | URL |
|---|---|---|
| ver2(最新) | 撮影中のリアルタイムカウント、再生しながらの高速解析、ポーズ推定はタッチの瞬間だけ | https://tym8912-bit.github.io/ifting-counter/ |
| ver1 | 最初の試作(撮影/アップロード→1フレームずつ解析) | https://tym8912-bit.github.io/ifting-counter/v1/ |

サッカーのリフティング動画を、ブラウザ内だけで解析して回数を数える試作アプリです。動画は外部に送信されません。

- アプリ内カメラで撮影 → 録画停止でそのまま解析(動画ファイルの読み込みにも対応)
- ボール検出: MediaPipe 物体検出(EfficientDet)または色追跡
- カウント: ボールの高さの推移から「落ちて、また上がった」最下点を1回として数える
- ポーズ推定(MediaPipe Pose)で接触部位(足・もも・頭・胸)を判定し、足元より下での跳ね返り(地面)は除外
- 軌跡・骨格の表示、高さのグラフ、イベント一覧、CSV出力などの検証機能付き

スマホのカメラを使うにはHTTPSで開く必要があるため、GitHub Pagesで公開しています。
